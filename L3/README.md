# Практика 3. Память в Unity

## Требования

- Windows 10 или новее.
- Unity `6000.3.16f1`.
- Поддержка сборки Windows с Mono. Дополнительный модуль IL2CPP для этой практики не нужен.
- Memory Profiler `1.1.12`, указан в зависимостях проекта.

## Первый запуск

1. Откройте проект через Unity Hub, выбрав эту папку проекта.
2. Дождитесь импорта и разрешения пакетов.
3. В Unity Editor выберите **Lesson 3 > Create Scenes and Build Development Player**.
4. Запустите `Build/UnityMemoryLab.exe`.

Практические измерения выполняются в Windows Development Player. Не используйте Editor Play Mode вместо собранного Player. В меню Unity Profiler подключайтесь к фактически запущенному процессу Player, а в Memory Profiler выбирайте **Attach to Player**.

Подробная последовательность находится в `Лекция_3_Память_Unity.md` из отдельного архива лекции. Инструкция к сдаче `ПРОВЕРКА_РАБОТЫ.md` входит в отдельный комплект проверки. Если все архивы распакованы в одну общую папку с сохранением структуры, эти документы будут на два уровня выше папки проекта.

## Проверка перед сдачей

Сдайте девять файлов, перечисленных в разделе «Что сдать» практической работы. Дополнительно передайте преподавателю изменённый `Assets/Scripts/AllocationExercise.cs`: checker проверяет артефакты, но не исходник. До отправки вручную откройте Profiler captures и Memory Profiler snapshots соответствующими инструментами.
